## Building

Requires TeX Live (with `biber` and `biblatex-ieee`) and `latexmk`:

```bash
latexmk -pdf main.tex
```

To refresh the page previews below after rebuilding:

```bash
rm -f preview/*.png && pdftoppm -png -r 110 main.pdf preview/page
```
